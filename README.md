# EXL3-serve

A fork from ddalcu's MLX-serve, focus only to support selected EXL3 models in Apple Silicon.

## Model support list

* Qwen3.8-Flash-Next
* MiMo-V2.6-Flash-RL

Any other `model_type`, and any `.gguf`, is refused at load by name.
